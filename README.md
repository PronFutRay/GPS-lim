# DriveGuard GPS & Autovelox (PWA para Android)

Aplicación web progresiva (PWA) de navegación GPS en tiempo real, velocímetro HUD y detector de radares (Autovelox / Tutor) lista para publicar en GitHub Pages e instalar como app nativa en Android.

## Contenido del paquete
- `index.html`: Aplicación completa con mapa oscuro, telemetría GPS en tiempo real, alertas sonoras/voz y simulación de ruta.
- `manifest.json`: Manifiesto W3C configurado en modo `standalone` (pantalla completa sin barra de navegador).
- `sw.js`: Service Worker para soporte offline e instalación nativa WebAPK en Android Chrome.
- `icon-192.png` y `icon-512.png`: Iconos oficiales de la aplicación.
